# BRIOFRAME Emergency Finish Design

## Objective
Finish the BRIOFRAME emergency launch as a revenue-ready, stable release today without expanding the definition of done into the entire future template roadmap.

## Current Baseline
- Shopify BRIOFRAME store is connected and active.
- Sixteen BRIOFRAME website-template products are active in Shopify.
- GitHub Pages public demo library is catalog-driven through `data/templates.json`.
- Batch 1 public demos are Velvet Nail Atelier, Amara Braid House, and Meridian Supply Co.
- Batch 1 exact Shopify purchase URLs are already registered in the catalog and embedded in demos.

## Emergency Definition of Done
The emergency build is complete when the current sellable inventory and public demo path are clean, consistent, and verifiably usable. Future category expansion remains a separate growth phase.

## GitHub Release Requirements
- Preserve the existing Batch 1 demo identities and exact Shopify destinations.
- Keep the public repository sanitized: no KSK material, credentials, paid source archives, customer data, or protected commercial masters.
- Add launch-readiness checks for SEO/indexing essentials: canonical URL, robots directives, sitemap availability, and useful page metadata.
- Keep the public demo library responsive and accessible.
- Do not label a public demo available unless its demo index and exact Shopify CTA are valid.
- Remove or block legacy LaunchPoint naming from publishable files.

## Shopify Release Requirements
- Preserve approved BRIOFRAME product titles, pricing, descriptions, and product identity unless a verified defect requires correction.
- Active sellable products should have a usable featured image; products missing media are launch blockers.
- Archived LaunchPoint products remain archived and are not reactivated.
- Digital-template inventory should not be treated like finite physical stock; negative inventory on an active digital product is a launch defect.

## QA Requirements
- Run the repository validator after changes.
- Verify Batch 1 Library → Demo → exact Shopify product paths.
- Verify public pages respond successfully and contain expected BRIOFRAME identity.
- Verify no publishable legacy LaunchPoint or KSK text appears.
- Verify active Shopify catalog has no negative inventory and no missing featured media before declaring completion.

## Scope Boundary
The emergency launch does not require every approved future vertical to be built today. Aviation, marine, fishing, clubs, villas, additional variants, media-house pitches, and other expansion work continue after the current revenue-ready baseline is complete.
