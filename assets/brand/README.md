# BRIOFRAME brand assets

## Present
- `favicon.svg` — derived from the existing site brand mark (`.brand__mark` “BR” lockup already used on the library and 404 pages). Not a new logo.
- `apple-touch-icon.png` — 180×180 brand-mark frame using the same navy/gold colors as the site brand mark (no invented logo artwork).

## Missing (do not invent)
- `og-share.png` — official Open Graph / social share image (recommended **1200×630** PNG or JPG).

Until an official `og-share.png` is added, pages must **omit** `og:image` and `twitter:image` metadata. Do not invent or generate an unofficial BRIOFRAME logo or share image. After the official asset is committed, add matching `og:image` / `twitter:image` tags that point to `/assets/brand/og-share.png` (validators require local social-image paths to resolve to real files).
