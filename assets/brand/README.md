# BRIOFRAME brand assets

## Present
- `favicon.svg` — derived from the existing site brand mark (`.brand__mark` “BR” lockup already used on the library and 404 pages). Not a new logo.

## Missing (do not invent)
- `og-share.png` — official Open Graph / social share image (recommended **1200×630** PNG or JPG).
- Optional: `apple-touch-icon.png` (180×180) when an official raster brand asset is available.

HTML already includes `og:image` / Twitter image metadata pointing at `/assets/brand/og-share.png`. Until that official file is added, social crawlers will not show a share preview image. Do not replace this with an unofficial generated logo.
